# GitHub para Iniciantes: Guia Prático de Versionamento e Colaboração

Material acadêmico desenvolvido para a disciplina **Desenvolvimento Front-End Para Web**, da Universidade Cruzeiro do Sul.

## Apresentação

Este repositório reúne uma cartilha digital e documentos complementares sobre os fundamentos do Git e do GitHub. O material foi elaborado para estudantes iniciantes e apresenta procedimentos que podem ser reproduzidos pela interface web do GitHub, sem exigir instalação do Git ou uso do terminal.

## Objetivo

Explicar conceitos de controle de versão, organização de repositórios, Markdown, commits, branches, Pull Requests, revisão e Merge. O projeto também propõe uma prática colaborativa para que os integrantes exercitem o compartilhamento e a revisão de alterações.
