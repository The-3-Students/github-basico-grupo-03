## 2. Finalidade do uso da inteligência artificial

A ferramenta de inteligência artificial foi utilizada como apoio à organização do trabalho, estruturação dos documentos, elaboração de explicações introdutórias, preparação de exemplos em Markdown e criação de roteiros para os exercícios realizados pelo navegador.

A IA foi tratada como ferramenta de apoio à produção textual e à aprendizagem, não como substituta da pesquisa, da conferência das fontes oficiais ou da execução das atividades pelos integrantes.

## 3. Primeiro prompt utilizado

O primeiro prompt foi utilizado para orientar o planejamento e a produção do projeto:

> Atue como professor universitário e especialista em Desenvolvimento Front-End, Git, GitHub e documentação técnica. Ajude a desenvolver uma cartilha digital em Markdown chamada “GitHub para Iniciantes: Guia Prático de Versionamento e Colaboração”, voltada a pessoas sem experiência. Explique Git e GitHub, repositórios, README, Markdown, commits, branches, Pull Requests, revisão, Merge e colaboração. Utilize português brasileiro, linguagem didática, exemplos reproduzíveis e documentação oficial.

## 4. Segundo prompt utilizado

O segundo prompt foi utilizado para solicitar revisão e verificação técnica:

> Revise o material sobre GitHub para iniciantes como um orientador acadêmico. Confira se os conceitos de Git, GitHub, repositório, commit, branch, Pull Request e Merge estão corretos. Verifique se os procedimentos descritos podem ser realizados pela interface web do GitHub e se os nomes dos menus correspondem à documentação oficial.

## 5. Exemplo de resposta da IA conferida, corrigida ou complementada

**Resposta da IA selecionada:** a distinção entre Git e GitHub.

**Síntese da resposta:** Git é um sistema distribuído de controle de versão que registra alterações nos arquivos. GitHub é uma plataforma online que hospeda repositórios Git e oferece recursos de colaboração, como Pull Requests e revisão de alterações.

## 6. Como as informações foram verificadas

A verificação deve considerar duas formas complementares:

1. **Pesquisa documental:** consultar a documentação oficial do GitHub, priorizando as páginas em português indicadas na cartilha.
2. **Verificação prática:** reproduzir os procedimentos na interface web do GitHub e observar os resultados na conta e no repositório do grupo.

Uma explicação da IA não deve ser considerada comprovada apenas por ter sido gerada. Quando a documentação oficial não confirmar um detalhe, o grupo deve corrigir, retirar ou apresentar a informação com a ressalva adequada.
